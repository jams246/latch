# Changelog

## 0.5.0 - 2026-11-02

- Replace the connections sidebar with a full-width library grouped alphabetically by initial.
- Open terminal and SFTP sessions directly from connection rows, with Edit and Delete in the overflow menu.
- Keep Connections pinned beside session tabs and reveal each tab's close control in place of its icon.
- Open Settings from the labeled gear in the top right, with Appearance, Data, and About sections.
- Add persistent Graphite and Citron app colors independently of terminal themes.
- Preserve existing profiles and backups while migrating saved app colors.

## 0.4.0 - 2026-10-26

- Open additional native windows with Duplicate to New Window from a terminal tab's context menu.
- Drag active terminal and SFTP tabs between existing windows without reconnecting or interrupting transfers.
- Share saved connections, sorting, terminal themes, and usage counts across windows while closing each window independently.
- Show a gripping hand cursor and floating tab preview with source dimming and invalid-drop feedback during tab dragging.

## 0.3.0 - 2026-10-25

- Add keyboard-accessible tab context menus with Duplicate and Close for terminal tabs and Close for SFTP tabs.
- Duplicate terminal tabs into independent sessions next to the original tab.
- Add an About page showing the application version, selected whenever Settings opens.
- Fix typing and text editing in rename and new-folder dialogs in both local and remote SFTP panes.

## 0.2.0 - 2026-10-24

- Display the application version beneath Settings and in executable properties.
- Include Latch in the window title.
